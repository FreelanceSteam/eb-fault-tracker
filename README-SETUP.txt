EB Fault Tracker PWA launcher

Upload every file in this folder to the ROOT of the existing GitHub repository, replacing index.html and app-tiles.png if asked. Do not upload the whole folder itself. Keep Admin.html and Technician.html as they are.

This makes the launcher installable as a PWA and caches the launcher shell. It does NOT make the Apps Script-backed dashboards work offline, and it does not replace or modify the Apps Script backend. The Technician button asks for the technician's existing personal Apps Script link; it does not store that link. The Admin button opens the existing Apps Script admin page.

After committing, open https://freelancesteam.github.io/eb-fault-tracker/ in Chrome and use the browser's Install app / Add to Home screen option. On iPhone, open the site in Safari, tap Share, then Add to Home Screen.
